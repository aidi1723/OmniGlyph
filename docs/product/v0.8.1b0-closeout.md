## What Changed（行为变化）

- 同一词条出现在多个命名空间时，已审核条目优先。多个已审核规范 ID 冲突时标记为歧义，输出护栏默认拦截。
- 大小写变体合并后，导入计数按实际写入的条目计算。
- 损坏的 UnicodeData 行使导入失败。命令行把这类输入错误写到 stderr，退出码为 2。后出现的坏行会与已写入的字形和来源记录一起回滚。
- 区间占位名 `<..., First>` / `<..., Last>` 在后续导入有正式名称或展开区间记录时被清除。显式名称在后续记录没有名称时保留。
- UnicodeData 和 Unihan 按记录流写入，不再把整份解析结果留在内存里。
- 除 `GET /api/v1/health` 外，HTTP 路由要求 `Authorization: Bearer $OMNIGLYPH_API_TOKEN`。健康检查只报告数据库文件是否存在。HTTP 响应省略机密词定义和本地路径。HTTP 访问词库包或策略包必须先配置对应根目录。stdio MCP 仍是本机进程，不使用这把令牌。
- 提交给扫描接口的文本超过 200000 个字符时，HTTP 返回 400，MCP 返回 `-32602`。本地 `scan-code` 把超限文件记为失败并继续扫描其余文件。
- 提示注入检查覆盖 ignore、disregard、forget、override、bypass，以及 “don't follow the previous rules” 和 “忘记之前的指令”。普通的较早邮件、会议记录，以及 “不要忘记之前的会议提示” 仍放行。
- 出站脱敏增加 GitHub token、Slack token 和私钥头。
- 与单个拉丁字母几乎相同的常见西里尔字母和希腊字母会标出对应拉丁字母。`π` 这类并不相同的字母仍只报跨文字风险。
- 可打印 ASCII 的代码扫描不再逐字查询 Unicode 名称和归一化。判定规则没有变。
- 发布冒烟把构建出的 wheel 装进不继承 `PYTHONPATH` 的干净虚拟环境，避免同版本可编辑安装让 pip 跳过入口脚本。
